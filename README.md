# Análise de Assinaturas Xbox Game Pass com Excel e IA

## Sobre o projeto

Este projeto foi desenvolvido como atividade prática do curso de Excel com Inteligência Artificial. O objetivo é utilizar o Excel para organizar dados de assinaturas do Xbox Game Pass, realizar análises de faturamento e apresentar os resultados em um dashboard.

A atividade utiliza tabelas dinâmicas e recursos de visualização para transformar os dados em informações que ajudam a compreender as vendas dos planos e dos serviços adicionais.

## Dados utilizados

A base contém **295 registros de assinantes**, com informações sobre planos, valores e serviços adicionais.

Entre as principais colunas utilizadas estão:

- **Subscriber ID:** identificador do assinante.
- **Name:** nome do assinante.
- **Plan:** plano contratado.
- **Start Date:** data de início da assinatura.
- **Auto Renewal:** indicação de renovação automática.
- **Subscription Price:** preço da assinatura.
- **Subscription Type:** periodicidade do plano.
- **EA Play Season Pass:** contratação do serviço adicional EA Play.
- **EA Play Season Pass Price:** valor do serviço EA Play.
- **Minecraft Season Pass:** contratação do serviço adicional Minecraft.
- **Minecraft Season Pass Price:** valor do serviço Minecraft.
- **Coupon Value:** valor do cupom.
- **Total Value:** valor total associado à assinatura.

## Estrutura da planilha

O arquivo está organizado em quatro abas:

- **Assets:** reúne elementos visuais, como cores, logos e ícones utilizados no projeto.
- **Bases:** contém os dados dos assinantes e suas respectivas informações.
- **Cálculos:** apresenta as perguntas de negócio e as análises realizadas com tabelas dinâmicas.
- **Dashboard:** reúne a apresentação visual dos resultados da análise.

## Análises realizadas

O projeto busca responder às seguintes perguntas de negócio:

1. Qual é o faturamento total das assinaturas de planos anuais?
2. Qual é o faturamento dos planos anuais, separado entre assinaturas com e sem renovação automática?
3. Qual é o valor total das vendas do EA Play Season Pass?
4. Qual é o valor total das vendas do Minecraft Season Pass?

As análises são realizadas no Excel e organizadas para facilitar a interpretação dos resultados por meio do dashboard.

## Ferramentas utilizadas

- **Microsoft Excel:** organização dos dados, cálculos, tabelas dinâmicas e dashboard.
- **Inteligência Artificial:** apoio durante o desenvolvimento da atividade, conforme os recursos utilizados no curso.

## Como reproduzir o projeto

1. Baixe o arquivo `atividade_3_oficial.xlsx` disponível neste repositório.
2. Abra a planilha no Microsoft Excel, preferencialmente em uma versão que ofereça suporte a tabelas dinâmicas e dashboards.
3. Acesse a aba `Bases` para consultar os dados utilizados na análise.
4. Vá até a aba `Cálculos` para verificar as perguntas de negócio e os resultados das tabelas dinâmicas.
5. Acesse a aba `Dashboard` para visualizar a apresentação dos resultados.
6. Caso altere ou substitua os dados da base, atualize as tabelas dinâmicas e confira os resultados antes de utilizar o dashboard.

## Objetivo de aprendizagem

A atividade permitiu praticar a organização de bases de dados, a análise de informações comerciais, o uso de tabelas dinâmicas e a construção de um dashboard no Excel, aplicando esses recursos à análise de assinaturas e faturamento.
